# Project Goal

To find a model that can successfully merge onto a highway and merge off the highway (per our environment specifications) as fast as possible without crashing into other vehicles. 

# MVP

 - 3 lane highway 
   - potential 4th lane for merging that disappears after a short length
 - Merges on the right
 - Destination exit is a left exit
   - on other side as entrance ramp
 - 1 km between the two exits
 - Randomized personality for other cars:
   - Normal / no personality
   - Faster speed
   - Slower speed
 - Randomized number of cars
   - Range (lowest and highest number of cars) TODO
