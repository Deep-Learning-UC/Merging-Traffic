1) install miktex - https://miktex.org/download (latex compiler)

2) download the james yu miktex vs code extension

3) make sure miktex is added to path (AppData/Programs/Miktex/miktex/bin/x64)

4) might have to restart vs code or something

5) open a .tex doc and click the green arrow in top right (ctrl alt b i believe)

6) a .aux, .fdb_latexmk, .fls, .log, and a .synctex.gz file are all created, in addition to the .pdf
